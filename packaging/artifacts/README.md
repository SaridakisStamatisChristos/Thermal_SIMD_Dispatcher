# Attestation Artifacts

This directory stores attestation materials bundled with releases.

## Contents
- `patcher_measurement.json` — SHA256 digests of patch buffers and controller binaries.
- `attestor_pub.pem` — Public key used to verify attestation service signatures.
- `release_manifest.json` — Optional metadata linking digest to release version and build ID.

Artifacts are generated by `make attestation-bundle` and uploaded to the secure artifact registry. During packaging, copy the desired release bundle into this directory before building the container or systemd packages.

## Verification
```bash
sha256sum patcher_measurement.json
openssl dgst -sha256 -verify attestor_pub.pem -signature patcher_measurement.sig patcher_measurement.json
```

Include updated digests in release notes and notify Security Engineering on changes.
